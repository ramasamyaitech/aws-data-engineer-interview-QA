 2. Difference between List and Tuple?

| List       | Tuple         |
| ---------- | ------------- |
| Mutable    | Immutable     |
| Uses []  | Uses ()     |
| Can modify | Cannot modify |

Example:


my_list = [1,2,3]
my_tuple = (1,2,3)


---

 3. Difference between append() and extend()?

 append()

Adds single element.


a = [1,2]
a.append([3,4])

print(a)
 [1,2,[3,4]]


 extend()

Adds multiple elements.


a = [1,2]
a.extend([3,4])

print(a)
 [1,2,3,4]
