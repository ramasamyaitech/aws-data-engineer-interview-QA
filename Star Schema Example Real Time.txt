=============================

Fact vs Dimension Table

| Feature     | Fact Table        | Dimension Table     |
| ----------- | ----------------- | ------------------- |
| Purpose     | Stores metrics    | Stores descriptions |
| Data Type   | Numeric           | Textual             |
| Size        | Very Large        | Smaller             |
| Records     | Billions possible | Thousands/Millions  |
| Aggregation | SUM, AVG, COUNT   | GROUP BY, FILTER    |
| Example     | Sales Amount      | Customer Name       |
| Keys        | Foreign Keys      | Primary Keys        |


Interview Question
Identify Fact and Dimension

| Column        | Table Type |
| ------------- | ---------- |
| Sales Amount  | Fact       |
| Quantity      | Fact       |
| Profit        | Fact       |
| Customer Name | Dimension  |
| Product Name  | Dimension  |
| City          | Dimension  |
| Date          | Dimension  |



Simple Rule

✅ Numbers you want to calculate → Fact Table

✅ Descriptions you want to filter/group by → Dimension Table

Example:

Revenue = Fact
Quantity = Fact
Customer = Dimension
Product = Dimension
Date = Dimension
Store = Dimension

# Business Query 1

## Total Transaction Amount by Customer

```sql
SELECT
    c.Customer_Name,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Customer c
ON f.Customer_Key = c.Customer_Key
GROUP BY c.Customer_Name;
```

---

# Business Query 2

## Total Deposit by Customer

```sql
SELECT
    c.Customer_Name,
    SUM(f.Amount) AS Deposit_Amount
FROM Fact_Transactions f
JOIN Dim_Customer c
ON f.Customer_Key = c.Customer_Key
WHERE f.Transaction_Type='Deposit'
GROUP BY c.Customer_Name;
```

---

# Business Query 3

## Total Withdrawal by Customer

```sql
SELECT
    c.Customer_Name,
    SUM(f.Amount) AS Withdrawal_Amount
FROM Fact_Transactions f
JOIN Dim_Customer c
ON f.Customer_Key = c.Customer_Key
WHERE f.Transaction_Type='Withdrawal'
GROUP BY c.Customer_Name;
```

---

# Business Query 4

## Total Transaction Amount by Branch

```sql
SELECT
    b.Branch_Name,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Branch b
ON f.Branch_Key = b.Branch_Key
GROUP BY b.Branch_Name;
```

---

# Business Query 5

## Total Transaction Amount by City

```sql
SELECT
    c.City,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Customer c
ON f.Customer_Key = c.Customer_Key
GROUP BY c.City;
```

---

# Business Query 6

## Monthly Transaction Report

```sql
SELECT
    d.Month,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Date d
ON f.Date_Key = d.Date_Key
GROUP BY d.Month;
```

---

# Business Query 7

## Savings vs Current Account Analysis

```sql
SELECT
    a.Account_Type,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Account a
ON f.Account_Key = a.Account_Key
GROUP BY a.Account_Type;
```

---

# Business Query 8

## Top 5 Customers

```sql
SELECT
    c.Customer_Name,
    SUM(f.Amount) AS Total_Amount
FROM Fact_Transactions f
JOIN Dim_Customer c
ON f.Customer_Key = c.Customer_Key
GROUP BY c.Customer_Name
ORDER BY Total_Amount DESC
LIMIT 5;
```

### Interview Explanation

**Fact Table**

* Transaction Amount
* Deposit Amount
* Withdrawal Amount
* Number of Transactions

**Dimension Tables**

* Customer
* Branch
* Account
* Date

**Granularity (Grain)**

* One row in Fact_Transactions = One Banking Transaction

This is a typical banking star schema used for transaction analytics, branch performance, customer analytics, and regulatory reporting.
