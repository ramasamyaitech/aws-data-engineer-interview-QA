
1. Find Duplicate Records

Find duplicate emails from a list.
emails = ["a@gmail.com", "b@gmail.com", "a@gmail.com", "c@gmail.com"]

duplicates = []

for email in emails:
    if emails.count(email) > 1 and email not in duplicates:
        duplicates.append(email)

print(duplicates)
Output:
['a@gmail.com']

3. Count Word Frequency

Find top occurring words in logs.
text = "error warning error failed error"

words = text.split()

freq = {}

for word in words:
    freq[word] = freq.get(word, 0) + 1

print(freq)
Output
{'error': 3, 'warning': 1, 'failed': 1}

5. Group Records by Department

Employee data processing.
employees = [
    ("IT","Ram"),
    ("HR","John"),
    ("IT","David")
]

result = {}

for dept,name in employees:
    result.setdefault(dept, []).append(name)

print(result)
Output
{'IT': ['Ram', 'David'], 'HR': ['John']}

7. Read Large File Efficiently

Log file processing.
with open("log.txt","r") as file:
    for line in file:
        print(line.strip())
Interviewers ask:
Why not read()?
Answer:
read() loads entire file into memory.

15. Generator for Large Data

Data Engineering interview favorite.
def numbers():
    for i in range(1000000):
        yield i

for num in numbers():
    print(num)
Why Generator?
•	Memory efficient
•	Loads data one by one

16. Decorator Question
def logger(func):

    def wrapper():
        print("Started")
        func()
        print("Completed")

    return wrapper

@logger
def process():
    print("Processing")

process()
Output
Started
Processing
Completed
