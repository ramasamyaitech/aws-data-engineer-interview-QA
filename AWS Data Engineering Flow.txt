```text id="e6ogkv"

    ↓

    ↓
```

---

# 1. S3 (Storage Layer)

Amazon Web Services S3 stores:

* CSV files
* JSON files
* Logs
* Parquet files

Example:

```text id="gm6ihw"
s3://sales-data/orders.csv
```

---

# 2. Glue Crawler

## What is Crawler?

Crawler automatically:

* Scans files in S3
* Detects schema
* Detects file format
* Creates metadata tables

Example:

* Reads CSV headers
* Finds columns:

  * order_id
  * customer_name
  * amount

---

# 3. Glue Data Catalog (CAT)

## CAT = Catalog

The crawler stores metadata inside:

AWS Glue Data Catalog

It acts like a metadata database.

Contains:

* Table names
* Column names
* File formats
* S3 locations

---

# Flow Example

```text id="jlwmqo"
orders.csv
    ↓
Crawler scans file
    ↓
Creates table in Glue Catalog
    ↓
Athena can query it
```

---

# 4. Glue ETL Job

## Purpose

Transforms data using PySpark.

Example:

* Remove nulls
* Convert date formats
* Join datasets
* Aggregate sales

---

# Glue Job Example

```python id="s8chrl"
from awsglue.context import GlueContext
from pyspark.context import SparkContext

sc = SparkContext()
glueContext = GlueContext(sc)

df = glueContext.create_dynamic_frame.from_catalog(
    database="sales_db",
    table_name="orders"
)
```

---

# 5. Athena

## What is Athena?

Amazon Athena allows SQL queries directly on S3 data.

No server required.

Example:

```sql id="h7f3ho"
SELECT * FROM orders
WHERE amount > 1000;
```

Athena uses:

* Glue Catalog metadata
* S3 files

---

# Athena Flow

```text id="7d4gl4"
S3 Data
   ↓
Glue Catalog
   ↓
Athena SQL Query
```

---

# 6. RDS

## What is RDS?

Amazon RDS is a managed relational database.

Supports:

* MySQL
* PostgreSQL
* Oracle
* SQL Server

Used for:

* OLTP applications
* Small-medium workloads

---

# Example Use Case

Application stores:

* Orders
* Users
* Payments

inside RDS.

---

# 7. Redshift

## What is Redshift?

Amazon Redshift is a Data Warehouse.

Used for:

* Analytics
* Reporting
* BI dashboards
* Huge datasets

Optimized for:

* OLAP queries

---

# RDS vs Redshift

| Feature    | RDS           | Redshift           |
| ---------- | ------------- | ------------------ |
| Type       | Database      | Data Warehouse     |
| Workload   | OLTP          | OLAP               |
| Usage      | Transactions  | Analytics          |
| Query Type | Small queries | Large aggregations |
| Scale      | Medium        | Massive            |

# Why Crawler is Important?

Without crawler:

* Need manual schema creation
* Manual table definitions
* Hard to manage changing files

Crawler automates metadata discovery.

---

# Important Interview Point

## Athena DOES NOT scan schema directly from S3 every time.

Athena mainly depends on:

* Glue Catalog metadata

created by:

* Glue Crawler
