List Methods

| `remove(x)`        | Remove first occurrence     |
| `pop()`            | Remove and return last item |
| `clear()`          | Remove all items            |
| `index(x)`         | Return index of item        |
| `count(x)`         | Count occurrences           |
| `sort()`           | Sort list                   |
| `reverse()`        | Reverse list                |
| `copy()`           | Create copy                 |


Tuple Methods

| Method     | Description          |

Set Methods

| Method              | Description                        |
| ------------------- | ---------------------------------- |
| `add(x)`            | Add an element                     |
| `update(iterable)`  | Add multiple elements              |
| `remove(x)`         | Remove element (error if absent)   |

String Methods in Python

| Method              | Description                         | Example                          |
| ------------------- | ----------------------------------- | -------------------------------- |
| `upper()`           | Convert to uppercase                | `text.upper()` → `"HELLO WORLD"` |
| `lower()`           | Convert to lowercase                | `text.lower()`                   |
| `title()`           | First letter of each word uppercase | `text.title()`                   |
| `capitalize()`      | First letter uppercase              | `text.capitalize()`              |
| `strip()`           | Remove spaces from both ends        | `" hi ".strip()`                 |
| `lstrip()`          | Remove left spaces                  | `" hi".lstrip()`                 |
| `rstrip()`          | Remove right spaces                 | `"hi ".rstrip()`                 |
| `replace(old, new)` | Replace substring                   | `text.replace("hello", "hi")`    |
| `split()`           | Split string into list              | `"a,b,c".split(",")`             |
| `join(iterable)`    | Join elements into string           | `"-".join(["a","b","c"])`        |
| `find(sub)`         | Return index of substring           | `text.find("world")`             |
| `index(sub)`        | Return index (error if not found)   | `text.index("world")`            |
| `count(sub)`        | Count occurrences                   | `text.count("l")`                |
| `startswith(sub)`   | Check prefix                        | `text.startswith("hello")`       |
| `endswith(sub)`     | Check suffix                        | `text.endswith("world")`         |
| `isalpha()`         | All characters are letters          | `"abc".isalpha()`                |
| `isdigit()`         | All characters are digits           | `"123".isdigit()`                |
| `isalnum()`         | Letters and numbers only            | `"abc123".isalnum()`             |
| `isspace()`         | All characters are spaces           | `"   ".isspace()`                |
| `len()`             | Length of string                    | `len(text)`                      |

def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n - 1)
